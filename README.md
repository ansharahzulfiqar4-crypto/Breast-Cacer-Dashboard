# 🎗️ Breast Cancer Analysis Dashboard

An interactive data analysis and visualization dashboard built using Python and Streamlit. This project explores breast cancer patient data through interactive charts, statistical summaries, and exploratory data analysis.

## 📌 Project Overview

The Breast Cancer Analysis Dashboard provides insights into patient demographics, cancer stages, tumor characteristics, hormone receptor status, lymph nodes, and recorded survival months.

The dashboard allows users to explore the dataset interactively using filters and visualizations.

## ✨ Features

- 📊 Interactive Dashboard Overview
- 👥 Patient Demographics Analysis
- 🩺 Cancer Stage Analysis
- 🎗️ Tumor Size and Grade Analysis
- 🧬 Hormone Receptor Analysis
- 🔬 Lymph Node Analysis
- 📈 Recorded Survival Months Analysis
- 🧪 Exploratory Data Analysis (EDA)
- 🔗 Relationship Analysis Between Variables
- 📁 Interactive Data Explorer
- 💡 Automatic Key Findings
- 🎨 Light Purple and Pink Dashboard Theme

## ⚙️ Installation

First, clone this repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Navigate to the project folder:

```bash
cd Breast-Cancer-Analysis
```

Install the required libraries:

```bash
pip install streamlit pandas numpy plotly matplotlib seaborn
```

## ▶️ Run the Dashboard

Run the following command in your terminal:

```bash
streamlit run cancer.py
```

The dashboard will open in your web browser.

## 📊 Dashboard Purpose

This project focuses on descriptive data analysis and visualization to explore patterns and relationships in the breast cancer dataset.
